## QUICK 1-2-3 DEPLOYMENT

### STEP 1: Local Prep (10 min)
```
cd C:\Projects\Hostinger-Deployment
npm install
npm run build
```

### STEP 2: Hostinger Setup (5 min)
```
https://hpanel.hostinger.com
Login → Hosting → Advanced → Node.js Apps → Create
Name: faith-impact-forum
Startup: server.js
Port: 3000
```

### STEP 3: Upload & Deploy (15 min)
```
File Manager → Upload app/, components/, lib/, public/, scripts/
Upload: package.json, server.js, .env.production, next.config.mjs
Terminal:
  npm install
  npm run build
  npm start
```

### RESULT:
```
✓ npm start shows: "Server running at http://0.0.0.0:3000"
✓ Visit: https://your-domain.com
✓ Website works!
```

## PROBLEM? QUICK FIXES

| Problem | Solution |
|---------|----------|
| npm install fails | `npm cache clean --force && npm install` |
| npm build fails | `npm install && npm run build` |
| npm start fails | Try again: `npm start` |
| Website won't load | Wait 10 min (DNS), then refresh |
| Files won't upload | Upload one file at a time |
| Terminal closes | Hostinger auto-restarts via PM2 |
