# COMMAND REFERENCE - COPY & PASTE READY
## Quick commands for on-site deployment

---

## PHASE 1: LOCAL SETUP (on their laptop)

```powershell
# Navigate to deployment folder
cd C:\Projects\Hostinger-Deployment

# Check Node.js
node --version
npm --version

# Install dependencies
npm install

# Build application
npm run build

# Verify build
ls .next
```

## PHASE 5: HOSTINGER TERMINAL COMMANDS

**Run these in Hostinger Terminal (one at a time):**

```bash
# Check current directory
pwd

# Install dependencies (WAIT 2-3 MINUTES)
npm install

# Build the project (WAIT 1-2 MINUTES)
npm run build

# START THE APPLICATION (CRITICAL!)
npm start
```

## IF SOMETHING GOES WRONG

**npm install fails:**
```bash
npm cache clean --force
npm install
```

**Build fails:**
```bash
npm install
npm run build
```

**Need to restart app:**
```bash
npm start
```

**Check what's running:**
```bash
pm2 status
pm2 logs
```
